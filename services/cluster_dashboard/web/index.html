HOW THE SYSTEM WORKS

一条业务，如何穿过这张网？

UE 发起业务，经模拟基站进入 5G 用户面，再由 Envoy 送往中心或边缘服务。控制面负责接入、鉴权、会话与策略管理。

当前能力边界

端口分类、代理转发、受控引导和容器 tc 带宽实验已有验证；自主业务识别、原生 5G QoS、动态编排与 Agent 尚未完成。此页面提供观测和解释，不能据此推导已具备这些能力。
